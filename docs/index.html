Battery Info Logger

A KernelSU Next WebUI module that samples your battery on an interval, charts the history in a dashboard, and exports the whole log as CSV.

Download latest zip Source on GitHub

What it does

Background logging

A daemon samples the battery every N seconds and appends a row to a persistent CSV that survives module updates.

Live dashboard

Level, current, temperature, voltage, health, cycle count, drain rate and ETA — plus three time-series charts.

CSV export

The manager's Action button (or the WebUI) writes the log to /sdcard/Download.

Metrics logged

epoch, iso, capacity, status, voltage_uv, current_ua, temp_dc,
charge_counter_uah, cycle_count, health, charge_full, charge_full_design

Read from /sys/class/power_supply/battery, falling back to google_battery and then to the first supply exposing capacity. Missing nodes are logged as empty fields.

Install

  1. Download battery_info.zip and copy it to the device.
  2. KernelSU Next manager → Modules → install from storage → pick the zip.
  3. Reboot. Logging starts automatically at a 60 s interval.

Auto-update

The module ships an updateJson pointer, so the manager checks for new versions on its own — no need to watch this page. When a release with a higher versionCode lands, the module shows an update badge and installs the new zip in place; your logged history is untouched. 

updateJson=https://kauri-off.github.io/battery_info/update.json

That manifest is served here and regenerated from module.prop at build time, so it can never drift from the shipped version. Changelog: CHANGELOG.md.

Build from source

git clone https://github.com/kauri-off/battery_info.git
cd battery_info
npm install
npm run build   # -> dist/battery_info.zip

The WebUI is React + Recharts bundled by Vite into a single self-contained index.html — the WebView has no asset paths to resolve. Run npm run dev to preview it in a browser with a mocked KernelSU bridge, no device required.
